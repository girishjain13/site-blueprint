 Requirements for the Streamlit deployment path (streamlit_app.py).
#
# This lives at the repo root as `requirements.txt` deliberately — testing
# against a real deployment showed Streamlit Community Cloud always reads
# `requirements.txt` from the repo root with no way to point it at a
# different file, regardless of what "Advanced settings" might suggest.
# So THIS is the one Streamlit Cloud will actually use.
#
# The FastAPI/Docker deployment path (app.py) needs a different, larger
# dependency set (fastapi, uvicorn, pydantic, playwright) — see
# requirements-docker.txt for that. Keeping them separate matters:
# installing streamlit and fastapi in the same environment causes a hard
# version conflict on their shared `starlette` dependency, which silently
# breaks the FastAPI app if both end up installed together.
#
# playwright is deliberately left out here — render_js is not recommended
# on typical free-tier memory limits, and crawler.py only imports it lazily
# (inside the crawl() method) when render_js is actually turned on, so it's
# not needed just to run the rest of the app. If you do want to try
# render_js on this host anyway, add `playwright==1.47.0` back in and note
# that Streamlit Cloud won't run `playwright install chromium` for you —
# that's a build-time step this platform doesn't expose.
